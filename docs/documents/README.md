# documents/

Put any PDFs (or other files) you want visitors to download here —
reports, flyers, publications, etc.

Then open `js/topics-data.js` and point a post's `file` field at it,
for example:

```
file: "documents/2026-rangeland-report.pdf"
```

The file name must match exactly (including capitalization) once the
site is live, since GitHub Pages is case-sensitive.
